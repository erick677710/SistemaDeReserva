# SistemaDeReserva
repositorio del un sistema de reserva para minimarkets


PROBLEMA (¿Qué dificultad queremos comprender?): 
La pérdida de tiempo en filas para compras rápidas de pocos productos y la incertidumbre de si hay stock disponible antes de ir al local.


CONTEXTO (¿Dónde y cuándo ocurre?): 
De regreso a casa o desde el trabajo, en momentos con poco tiempo disponible y operando la interfaz desde un dispositivo móvil en movimiento.


IDEA INICIAL (¿Qué solución imaginamos por ahora?):
Una web móvil rápida que permita seleccionar productos del minimarket, reservarlos y recogerlos/pagarlos directamente en caja.


USUARIO (¿Quién vive esa dificultad?): 
Vecinos del barrio o clientes habituales que necesitan realizar compras exprés desde sus smartphones.


TAREA (¿Qué intenta hacer el usuario?): 
Explorar el catálogo disponible, armar una lista de compra en pocos clics y enviar la reserva para recojo.


ALCANCE (¿Qué parte pequeña abordaremos primero?): 
Un catálogo con buscador básico, un carrito de compras express con formulario mínimo (nombre y teléfono) y una pantalla simple con el estado del pedido.

HIPOTESIS: Creemos que el vencino del barrio necesita poder ver el catalogo de los minimarkets cerca de su destino para evitar peder tiempo buscando productos en tiendas que no tengan el objeto que buscando.
si le enseñamos una web para reservar productos esperamos que  pueda hacer sus compras mas rapido.
